# Dear Jake

텍스트 중심의 반응형 심리 미스터리 비주얼 노벨입니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 열어 플레이할 수 있습니다. 로컬 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 사용합니다.

```powershell
python -m http.server 4173
```

그다음 브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 조작

- 하단 삼각형 버튼, 화면의 텍스트 박스, `Enter`, `Space`: 대사 진행
- 선택지: 마우스, 터치 또는 숫자 키
- `기록`: 지나간 대사 확인
- `설정`: 글자 속도, 자동 진행, 전체 화면, 처음부터 시작

진행 상황과 설정은 브라우저에 자동 저장됩니다.
